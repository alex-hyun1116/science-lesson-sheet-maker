# 매쓰팜 과학 문제 설명 자료

ChatGPT로 만든 과학고 기출 설명지 데이터를 문제별 수업자료 형태로 정리하고 출력하는 로컬 웹앱입니다.

## 이 앱이 하는 일

- ChatGPT가 만든 설명지 데이터를 한 번 가져와 문제별 수업자료를 자동 생성합니다.
- 설명지, 원본 문제 이미지/PDF, 추가 이미지를 `data/app-state.json` 파일에 자동 저장합니다.
- 상단의 `백업 저장`으로 별도 JSON 파일을 내려받아 보관하고, `백업 불러오기`로 다시 추가할 수 있습니다.
- 학생용/강사용 표시 옵션을 바꿔 A4 또는 PDF로 출력합니다.
- `현재 화면 인쇄`는 보고 있는 학생용/강사용 상태 그대로 출력합니다.
- 문제 목록 화면의 `학생용 전체 PDF`는 강사용 설명을 제외하고, `강사용 전체 PDF`는 강사용 설명까지 포함해 출력합니다.
- 생명/화학, 물리/지구 대분류와 생명, 화학, 물리, 지구 과목을 구분해 관리합니다.

## 이 앱이 하지 않는 일

- AI 분석을 직접 하지 않습니다.
- PDF를 자동으로 읽거나 문제를 자동 풀이하지 않습니다.
- 로그인, 학생 계정, 서버 DB는 없습니다.

## 실행 방법

```powershell
npm.cmd run dev -- --port 5173
```

명령을 실행하면 내 컴퓨터에서만 접속 가능한 개발 서버가 켜집니다.

브라우저 주소:

```txt
http://127.0.0.1:5173/
```

터미널을 닫거나 `Ctrl+C`를 누르면 서버가 꺼집니다.

## 데이터 보관 주의

앱은 기본적으로 프로젝트 폴더의 `data/app-state.json` 파일에 자동 저장합니다. 개발 서버를 껐다 켜도 이 파일이 남아 있으면 자료가 다시 불러와집니다.

예전 버전은 브라우저 저장소에 저장했기 때문에 브라우저가 달라지거나 주소가 `localhost`/`127.0.0.1`처럼 달라지면 자료가 안 보일 수 있었습니다. 앞으로는 파일 자동 저장이 기본이고, 중요한 작업 후에는 상단의 `백업 저장`으로 별도 백업 파일도 남겨두면 더 안전합니다.

## 기본 흐름

1. 문제집 PDF 또는 원본 사진을 등록합니다.
2. 같은 PDF를 외부 ChatGPT에 올려 전체 문제 분석 결과를 만듭니다.
3. ChatGPT가 만든 전체 JSON을 앱의 `ChatGPT 설명지 가져오기`에 한 번 넣습니다.
4. 앱이 문제별 설명지를 자동 생성합니다.
5. 학생용/강사용 화면으로 확인하거나 인쇄합니다.

## 구조

- 프론트엔드: React + Vite
- 로컬 저장 API: Vite 개발 서버의 `/api/state`
- 저장 위치: `data/app-state.json`
- 배포 서버: 없음

즉, `npm.cmd run dev`는 앱 화면과 로컬 파일 저장 API를 함께 켜는 명령입니다. 외부 서버나 로그인은 없습니다.

## 현재 데이터 모델

문제집은 대략 아래 구조로 가져옵니다.

```json
{
  "workbookTitle": "",
  "school": "",
  "year": "",
  "group": "생명/화학",
  "subjects": ["생명", "화학"],
  "problems": []
}
```

`group`은 `생명/화학` 또는 `물리/지구` 중 하나입니다. 각 문제의 `subject`는 `생명`, `화학`, `물리`, `지구` 중 하나를 사용합니다.

각 문제는 `problemNumber`, `title`, `subject`, `unit`, `sourcePages`, `questionSummary`, `verificationStatus`, `keywords`, `concepts`, `clues`, `conceptFlows`, `subQuestions`, `commonMistakes`, `teacherGuide`를 사용합니다.

## 주의할 점

- `data/app-state.json` 파일을 삭제하거나 다른 폴더에서 앱을 실행하면 기존 자료가 안 보일 수 있습니다.
- 다른 PC로 옮길 때는 `백업 저장`으로 받은 JSON 파일을 `백업 불러오기`로 추가하면 됩니다.
- 기존 `융합과학` 데이터는 앱이 깨지지 않도록 화학 쪽으로 안전하게 보정됩니다. 새 JSON에서는 `융합과학`을 subject로 쓰지 말고 keywords에 `융합` 등을 넣습니다.

## 주요 파일

- `src/main.jsx`: 앱 기능과 화면 구성
- `src/styles.css`: 화면 스타일과 인쇄 스타일
- `package.json`: 실행/빌드 명령
